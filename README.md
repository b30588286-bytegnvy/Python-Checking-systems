Python System Checker

Simple Python system diagnostics and monitoring tool.

Features

- System information
- CPU and RAM monitoring
- Disk usage analysis
- Network status check
- Internet connectivity test
- Running processes list
- Battery information
- Uptime monitoring
- Large files scanner
- JSON report generation
- Simple encrypted backup
- Email report sending
- Log file support

Requirements

Install dependencies:

pip install psutil

Run

python main.py

Generated Files

- "system_report.json"
- "system_report.enc"
- "log.txt"

Platform Support

- Android (Pydroid 3)
- Linux
- Windows

Some functions may be limited on Android because of system permission restrictions.

Example Data

{
    "cpu_percent": 21.5,
    "ram_percent": 43.2,
    "internet": true
}

Warning

This project is for:

- diagnostics
- monitoring
- educational purposes

Do not use it on systems without permission.
